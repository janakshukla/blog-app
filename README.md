# 📝 Blog App

**Blog App** is a modern web application that allows users to create, read, update, and delete blog posts. Built with React.js and integrated with Appwrite for backend services, it offers a seamless and efficient blogging experience.

🔗 **Live Demo**: [blog-app-khaki-three.vercel.app](https://blog-app-khaki-three.vercel.app)

---

## ✨ Features

* 🖊️ **Create and Manage Posts**: Users can compose new blog posts and manage existing ones.
* 🔍 **Read Posts**: Browse through a collection of blog entries.
* 🛠️ **Edit and Delete**: Modify or remove blog posts as needed.
* 🔒 **Secure Backend**: Utilizes Appwrite for authentication and database management.
* 🎨 **Responsive Design**: Ensures optimal viewing on various devices.

---

## 🛠️ Tech Stack

* **Frontend**: [React.js](https://reactjs.org/)

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:

* [Node.js](https://nodejs.org/) (v14 or later)
* npm or yarn

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/janakshukla/blog-app.git
   cd blog-app
   ```

2. **Install dependencies**:

   Using npm:

   ```bash
   npm install
   ```

   Or using yarn:

   ```bash
   yarn install
   ```

3. **Configure Environment Variables**:

   Create a `.env` file in the root directory and add your Appwrite project credentials:

   ```env
   VITE_APPWRITE_ENDPOINT=your_appwrite_endpoint
   VITE_APPWRITE_PROJECT_ID=your_project_id
   VITE_APPWRITE_DATABASE_ID=your_database_id
   VITE_APPWRITE_COLLECTION_ID=your_collection_id
   ```

4. **Start the development server**:

   Using npm:

   ```bash
   npm run dev
   ```

   Or using yarn:

   ```bash
   yarn dev
   ```

   Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
